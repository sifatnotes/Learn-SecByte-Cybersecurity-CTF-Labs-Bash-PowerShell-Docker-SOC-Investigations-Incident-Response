# Learn SecByte Scripting, Container Security & SOC CTF Labs

A curated collection of **hands-on cybersecurity labs and CTF challenges** covering Bash scripting, PowerShell security, command injection, Docker, AppArmor, SOC investigations, shift handovers, incident documentation, and executive incident communication.

This repository is intended for cybersecurity students, CTF players, aspiring SOC analysts, penetration testers, and security professionals developing practical technical and operational skills.

## Introduction

These Learn SecByte labs span two complementary areas of cybersecurity:

- **Technical security:** scripting, command injection, cron jobs, Docker, and AppArmor.
- **Security operations:** threat hunting, SOC workflows, investigation closure, shift handovers, and incident communication.

Use this repository as a searchable index for authorized hands-on learning and defensive security practice.

## How to Use the Labs

1. Open each challenge through its direct Learn SecByte URL.
2. Review the lab objectives and permitted testing scope.
3. Complete technical exercises only in the intended environment.
4. For SOC labs, document investigation steps, evidence, findings, and recommended actions.
5. Practice clear handovers and audience-appropriate incident communication.
6. Keep credentials, sensitive data, and private incident details out of public notes.
